view_module Core Modules

Authentication

@Module/Auth

Handles JWT issuing, verification, and OAuth2 integrations. Tightly coupled with the Users module for profile validation.

Component Responsibility
JwtStrategy Validates bearer tokens attached to incoming requests.
AuthGuard Protects routes, ensuring active session exists.

Users Management

@Module/Users

Manages user lifecycle, roles, permissions (RBAC), and profile data synchronization.

Component Responsibility
UsersService CRUD operations and business logic for User entities.
RolesGuard Verifies user permissions against route requirements.
